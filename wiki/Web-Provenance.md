# Происхождение web-находок

В 1.5.0 `domain` разделяет HTTP-ответ, извлечённый state/script и объявленный
исходник source map. Scope использует revision `1.5.0-web-source-v1`.
Этот контракт относится к наблюдаемым текстам выбранного обхода; он не доказывает
полный inventory сайта, удалённое отсутствие секрета или неизменность deployment.

`provenance.digest` — SHA-256 текста конкретного Item:

- `web-response` — байты тела, прочитанные через `net/http`;
- `web-response-prefix` — сохранённый ограниченный prefix при ошибке чтения,
  закрытия или лимите; отчёт остаётся неполным;
- `web-state-script` — целый извлечённый script без изменения его текста
  декодером, после удаления окружающих пробелов;
- `web-state-decoded` — обработанный state, meta или regex-фрагмент без
  удостоверенного исходного контекста;
- `source-map-content` — логическая строка `sourcesContent` после разбора JSON.

`container_digest` отдельно сохраняет SHA-256 наблюдаемых байтов HTTP-контейнера.
Для внешней карты это тело карты, для inline-карты — содержащий её JS, для state —
HTML-ответ. При неполном чтении digest относится только к сохранённому prefix.
Это не hash сетевого wire stream, ETag, подписи сайта или реального исходного
файла до сборки. Автоматическая обработка content encoding транспортом предшествует
чтению тела. `source_url` указывает безопасный адрес последнего принятого ответа;
он не содержит credentials, query или fragment.

Обычный HTTP URL в SARIF очищен от приватных selectors. Производные представления
используют URI `web+http(s)://host/path#kind/ordinal/label`. Fragment здесь —
локатор представления, не сетевой запрос. Повторные имена `sourcesContent` и
несколько inline-карт получают разные URI и private identities. URI сохраняется
в SARIF и индексе; JSON сохраняет прежний display path, parent provenance,
transform и идентификаторы. Позиции относятся к наблюдаемому или извлечённому
тексту; преобразование координат обратно в HTML/JS-контейнер не утверждается.

Keyed report identity и индекс учитывают приватный URL selector. Публичный URI
его не раскрывает; без report key fingerprint использует публичный namespace.
Одинаковое значение сохраняет общий secret/value ID. Keyed occurrence также
учитывает digest контейнера: изменение ответа может создать новое наблюдение
того же логического текста. Старые parent producer metadata и source locator
не переносятся через новую `Discover` acquisition boundary.

Декодированное представление не становится новым доказательством соседства
учётных данных. `web-state-decoded` не передаёт companions составному verifier
или публичному аудитору; независимая проверка отдельного ключа возможна по явному
`--verify`. Неизменённый полный script и `sourcesContent` сохраняют существующие
ограниченные правила разбора конфигурации. Эти правила не исполняют JavaScript.
При замене builtin-кандидата более сильным rule отметка представления сохраняется,
в том числе для mobile printable strings.

Ошибки web source передаются в pipeline с безопасным текстом и путём. Сырые
transport/parser ошибки могут содержать URL или ответ сервера, поэтому не отражаются
в stderr. Читаемый prefix сохраняется вместе с диагностикой неполноты; ошибка не
получает выдуманный digest. Baseline и индекс сохраняют обычные incomplete guards.

Отбор crawler, same-origin ограничения, retry, бюджеты и body dedup не расширены.
Одинаковые тела могут представляться первым URL в установленном порядке, а
одинаковые state-тексты — первым подходящим контейнером. Это не перечень всех URL,
на которых опубликовано одинаковое значение. Права провайдеров, реальный аккаунт
и успешный внешний HTTP-доступ отдельно не квалифицируются этим контрактом.

Воспроизводимая нативная проверка:

```sh
python3 scripts/check_domain_provenance.py /path/to/prowl
```

Runner создаёт отдельный `PROWL_HOME`, собственный HTTP-сайт и индекс. macOS sandbox
разрешает только loopback-порт этого сайта; второй собственный порт проверяется
как запрещённый. Используются синтетические значения и явная Go-модель с 51
признаком. Evidence — `evidence/1.5.0-web-provenance-20261115.json`.
Это source/native darwin-arm64 квалификация; Docker/Linux, hosted CI, реальные
сайты, recon и production runtime требуют отдельных доказательств.
